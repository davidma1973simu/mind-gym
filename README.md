# 探奇 / Mind Gym

AI 原生一代的"思维肌肉"训练器。不给你答案，逼你长出**发现、洞察、定义、验证**的能力——在 AI 时代不被废掉思考。

## 当前状态

- **M1 · 无 AI 闭环（已上线）** —— 纯前端 + `localStorage`，零后端、零 Key 也能跑完一周循环：
  - 📡 **捕捉**（权重 30%，产品灵魂）：文字 / 语音 / 拍摄 / 链接多源输入；主动🔆 / 被动🌧️ 标记。
  - 🗂️ **分拣**：捕捉池引导式「推 / 弃 / 存」，只推想定义的进入下一步。
  - 💡 **定义**（权重 30%）：4 步轻引导（核心 → 目标 → 卡点 → 成功标准），生成问题卡。
  - 🤔 **先想再做**（权重 10%）：P1 门禁——先写自己的倾向与理由，再看下一步（AI 视角 M2 启用）；含验证规划 + 高风险标记。
  - 🧪 **验证**（权重 20%）：行动 + 预期 vs 实际 + 有效 / 错误；高风险问题强制核对原始资料再闭环。
  - 🌱 **我的成长**：对话式姓名、四维能力雷达（发现 / 定义 / 验证 / 校准，真实本地计算）、判断日志（长期资产）。
  - 休闲性非强制：不打卡、不催、未闭环不标逾期。
  - 中国轻量合规：<14 岁监护人手机号 + 同意勾选门禁。
- 开发计划（线下产品文档）：M2 AI 协作（接用户自带 Key）+ 真判断日志 → M3 多源捕获 / 社媒分享 → M4 订阅 / 后台。

## 技术

静态站点，零构建：`index.html` + `style.css` + `app.js` + `manifest.json` + `icon.svg`。数据存浏览器 `localStorage`（key: `mindgym_v1`）。

## 本地预览

直接用浏览器打开 `index.html`，或 `npx serve`（需 `localStorage`，建议用 http 而非 file:// 以启用部分能力）。
