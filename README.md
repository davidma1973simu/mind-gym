# 探奇 / Mind Gym

AI 原生一代的"思维肌肉"训练器。不给你答案，逼你长出**发现、洞察、定义、验证**的能力——在 AI 时代不被废掉思考。

## 当前状态

- **M1.5 · 引导式对话 + 自带 Key AI（已上线）** —— 三个核心环节全部改为「一次只问一个问题」的对话流，非表单。每步答案可点「改 ✎」回看修订，后续答案自动作废重走。
  - 📡 **捕捉**：极简输入 + 多源；主动🔆/被动🌧️；首页 About 4 张轮播（目的/价值/流程/姿态）下沉到输入与探索池之后，首屏保持极简。
  - 🗂️ **探索池**：推进 / 放弃 / 归档 + 彻底删除（二次确认）；入口常驻首页「我的探索」折叠条右侧。
  - 💡 **定义**：**五步问题定义法** 对话——① 现状（只写事实）② 标准 ③ 差距（只写一个）④ 后果（要具体）⑤ 问题定义（模板自动拼前四步，必须可验证）。
  - 🤔 **协作**：先给方向 + 理由（你的判断先到），再选 AI 两种协作——🛠️ 出完整方案 / ⚔️ 挑战反驳你的判断——最后合成方案。AI 走用户自带 Key（OpenAI 兼容），失败/无 Key 回落本地模板并**明确标注来源**，绝不假装智能。
  - 🧪 **验证**：先给验证建议（可让 AI 定制）→ 原型测试做了啥 → 真实结果 → 有效/错了 → 修订。高风险（钱/安全/健康/法律）强制贴来源才能收尾。
  - 🌱 **我的成长**：四维能力雷达按对话答案真实计算。
  - 休闲性非强制；<14 岁监护人手机号 + 同意门禁。
- **M1 遗留**：AI Key 由用户在首页右上角 ⚙️ 设置（DeepSeek/OpenAI/自定义），仅存本地。真实 API 调用需浏览器直连，注意 CORS。

## 技术

静态站点，零构建：`index.html` + `style.css` + `app.js` + `manifest.json` + `icon.svg`。数据存浏览器 `localStorage`（key: `mindgym_v2`）。

## 本地预览

直接用浏览器打开 `index.html`，或 `npx serve`（需 `localStorage`，建议用 http 而非 file:// 以启用部分能力）。
