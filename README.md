# 探奇 / Mind Gym

AI 原生一代的"思维肌肉"训练器。不给你答案，逼你长出**发现、洞察、定义、验证**的能力——在 AI 时代不被废掉思考。

## 当前状态

- **M1 · 无 AI 闭环（已上线）** —— 纯前端 + `localStorage`，零后端、零 Key 也能跑完一周循环。以一条贯穿全流程的「线索」对象为核心：
  - 📡 **捕捉**（权重 30%，产品灵魂）：首页极简输入 + 多源（文字 / 语音 / 拍摄 / 链接）；主动🔆 / 被动🌧️ 标记；提交后即时反馈卡 + 引导去线索池。
  - 🗂️ **整理 / 分诊**：用户驱动的「推进 / 放弃 / 归档」，只有点「推进」的线索才进入下一步，绝不自动推。
  - 💡 **定义**（权重 30%）：4 步轻引导（核心 → 目标 → 卡点 → 成功标准），每步输出「本步小结」卡。
  - 🤔 **先想再做**（权重 10%，P1 门禁）：先写自己的判断 + 理由才能继续（阻断式），再展开示例思路；含高风险标记。
  - 🧪 **验证**（权重 20%）：行动 + 预期 vs 实际 + 有效 / 错误；高风险问题强制贴来源才能闭环。
  - 🌱 **我的成长**：对话式姓名、四维能力雷达（发现 / 定义 / 验证 / 校准，真实本地计算）、判断日志（长期资产）。
  - 阶段屏统一模板：顶部「← 家 / 阶段标识 / 💾 存草稿」+ WHY 行 + 帮助「?」+ 本步小结 + 固定「下一步」提示；任何阶段可一键回首页。
  - 休闲性非强制：不打卡、不催、未闭环不标逾期。
  - 中国轻量合规：<14 岁监护人手机号 + 同意勾选门禁。
- 开发计划（线下产品文档）：M2 AI 协作（接用户自带 Key）+ 真判断日志 → M3 多源捕获 / 社媒分享 → M4 订阅 / 后台。

## 技术

静态站点，零构建：`index.html` + `style.css` + `app.js` + `manifest.json` + `icon.svg`。数据存浏览器 `localStorage`（key: `mindgym_v2`）。

## 本地预览

直接用浏览器打开 `index.html`，或 `npx serve`（需 `localStorage`，建议用 http 而非 file:// 以启用部分能力）。
